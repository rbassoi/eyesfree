# @eyesfree/browser

All of [EyesFree](https://github.com/rbassoi/eyesfree) in a single file (about 15 kB gzipped) for `<script>` tags, CMSs and WebViews. No build step.

```html
<script src="https://unpkg.com/@eyesfree/browser/dist/eyesfree.min.js" data-eyesfree-auto data-root="#app"></script>
<button data-eyesfree-open>👓 No glasses?</button>
```

📚 [API reference](https://github.com/rbassoi/eyesfree/blob/main/docs/api/browser.md) · Apache-2.0 (keep the NOTICE file).
