# @eyesfree/calibrator

`<eyesfree-calibrator>` is the two-step perceptual calibration wizard of [EyesFree](https://github.com/rbassoi/eyesfree), packaged as a framework-agnostic, accessible and localised Web Component (en, pt-BR, es).

```bash
npm install @eyesfree/calibrator
```

```ts
import { openCalibratorDialog } from '@eyesfree/calibrator';
const profile = await openCalibratorDialog({ engine }).result;
```

📚 [API reference](https://github.com/rbassoi/eyesfree/blob/main/docs/api/calibrator.md) · Apache-2.0 (keep the NOTICE file).
