# @eyesfree/react

React bindings for [EyesFree](https://github.com/rbassoi/eyesfree): `<EyesFreeProvider>`, `useEyesFree()` and `<EyesFreeCalibrator>`.

```bash
npm install @eyesfree/react
```

```tsx
<EyesFreeProvider options={{ root: '#root' }}><App /></EyesFreeProvider>
const { active, toggle } = useEyesFree();
```

📚 [API reference](https://github.com/rbassoi/eyesfree/blob/main/docs/api/react.md) · Apache-2.0 (keep the NOTICE file).
